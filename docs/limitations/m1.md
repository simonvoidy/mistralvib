# M1 — Launcher shell: known limitations

- No game functionality: instances persist and validate, but nothing is installed or launched.
- Accounts, Java runtime, Controls editor, Settings screens are placeholders that document
  their planned milestone.
- Version input on instance creation is free text; it is not yet validated against the
  Mojang manifest (M2).
- The touch control schema ships and round-trips, but no overlay/editor exists.
- The Zalith-layout import adapter is tolerant and best-effort: percent-based coordinates
  are mapped, exotic fields (special button textures, pointer capture details) are skipped
  and reported in the import result.
- Compilation and tests are verified by CI, not in this repository's authoring sandbox.
